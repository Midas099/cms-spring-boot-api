Spring Boot project (Maven). The full project with pom.xml is in the zip archive.

Course Management System - a university e-journal, that can be used both by students and teachers.
Context: Educational project, which was written as a final task in ATL Academy, 2024, written together with my colleague. My part was creating classes' DTO,
controllers and repositories; and testing HTTP methods via POSTMAN in order to verify APIs behavior.
Technologies: Java, SpringBoot, Postman for API testing.
Functions: students, teachers, courses, semesters, exams, results, announcements, login and registration; main operations (GET, POST, PUT, DELETE).
